🔓 OWASP Top 10 Vulnerabilities

All vulnerabilities deliberately implemented for VulnShield scanning demo

A01:2021
CRITICAL
Broken Access Control
Admin panel accessible to any logged-in user (no role check). IDOR: any user reads/modifies other users' data via /api/user/:id. Horizontal privilege escalation possible.
/admin → any user can access
/api/user/1 → returns admin's card+CVV
A02:2021
CRITICAL
Cryptographic Failures
Passwords stored in plaintext. API exposes card numbers, CVV, passwords. No HttpOnly/Secure cookie flags. API keys hardcoded in source code.
/api/profile → password, card, CVV
/api/admin/users → all creds leaked
A03:2021
CRITICAL
Injection — XSS
Search query reflected unsanitized in response. Username reflected in login error without encoding. No Content-Security-Policy header to block script execution.
/api/search?q=<script>alert(1)</script>
A04:2021
HIGH
Insecure Design
No CSRF protection on fund transfer. Business logic flaw: negative transfer amount steals money from victim. No input validation or balance check.
POST /api/transfer amount=-99999
→ Steals ₹99,999 from target!
A05:2021
HIGH
Security Misconfiguration
Missing CSP, X-Frame-Options, HSTS, X-Content-Type-Options. Debug endpoint exposes all env vars, sessions, passwords. Directory traversal via /api/file?name=../../
/debug → ALL secrets exposed
/api/file?name=../../etc/passwd
A06:2021
HIGH
Vulnerable & Outdated Components
jQuery 1.8.3 (CVE-2015-9251, CVE-2019-11358, CVE-2020-11022). Bootstrap 3.3.4. OpenSSL 1.0.2k (EOL). No SRI on CDN scripts.
jquery-1.8.3.min.js (no integrity=)
bootstrap/3.3.4 (no SRI hash)
A07:2021
HIGH
Identification & Auth Failures
No brute-force protection. Weak passwords (admin123, 123456) accepted. Session token exposed in URL. No HttpOnly/Secure cookie. Predictable sequential session IDs.
/profile?token=sess_1001_admin
Cookie: token=sess_1001_admin (readable by JS)
A08:2021
MEDIUM
Software & Data Integrity Failures
No SRI hashes on CDN scripts — supply chain attack possible. Unsafe deserialization of base64 cart data allows privilege escalation by injecting role field.
POST /api/restore-cart
cartToken = base64({role:"admin"})
A09:2021
MEDIUM
Security Logging & Monitoring Failures
Zero security event logging. Failed logins not logged. Data access events not audited. No alerts for suspicious activity. Admin access not tracked.
/api/logs → [] (empty!)
No audit trail exists
A10:2021
CRITICAL
Server-Side Request Forgery (SSRF)
Server fetches any URL supplied by user. Can access internal metadata services, internal APIs, or local files. No URL validation or allowlist.
POST /api/webhook/fetch
{"webhookUrl":"http://169.254.169.254/latest/meta-data/"}
